# MarocBR

MarocBR — Moroccan battle-royale web game, 2D top-down, 1 player vs 9 bots.

- **Team:** ElMehdi (project lead, last word) · Muse (intermediary / file organiser) · Claude (sole coder / architect) · Gemini (creative / reviewer, on trial)
- **Play:** open `index.html` in Chrome on Android, or play the shared link. JOUER starts the match directly.
- **Current version:** 6 balanced Dofus-style heroes (Salma, Omar, Lina, Rayan, Nour, Adam), 4 city maps (Fès, Casablanca, Marrakech, Tanger), Brawl Stars controls — hold TIRER = auto-aim on the nearest enemy (no shot), release TIRER = one auto-aimed shot. Visible fists punch when unarmed, 3 cars as obstacles, 10-minute zone in 5 phases.

See `DECISIONS.md` for the validated rules and `TACHES.md` for the task list.
